# Database Runbook

## Symptoms

- Database connection failures
- Slow query performance
- High CPU or memory usage
- Database service unavailable
- Replication lag

## Troubleshooting

1. Verify database service status.
2. Check database connection pool usage.
3. Review database error logs.
4. Identify long-running or blocked queries.
5. Verify disk space and system resources.
6. Check replication status and synchronization.
7. Confirm network connectivity between application and database servers.

## Resolution

Restart the database service if required, optimize or terminate long-running queries, restore available disk space, and re-establish replication if synchronization has failed.
